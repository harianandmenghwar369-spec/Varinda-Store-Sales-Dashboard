# Varinda Store — Interactive Sales Dashboard

An interactive Excel dashboard built to analyze and visualize
retail sales performance for Varinda Store.

## Features

- Monthly and yearly sales trend charts
- Product category performance breakdown
- Top-selling products ranking
- Revenue vs target KPI tracker
- Interactive slicers for dynamic filtering
- Automated data refresh with one click

## Tools used

- Microsoft Excel
- Pivot Tables & Pivot Charts
- Excel Slicers & Timelines
- Conditional Formatting
- VBA Macros (auto-refresh)

## How to use

1. Download the Excel file
2. Enable macros when prompted
3. Use the slicers on the left to filter by month, category, or product
4. All charts update automatically
